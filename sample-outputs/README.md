# Sample Outputs

Example outputs showing what Gemini Nano Bana can generate from the prompts in this library.

## Files

### notebook-style.svg
A hand-drawn notebook-style SVG showing PySpark concepts with:
- Colored boxes (navy, blue, green, red)
- Arrows and connectors
- Code snippets
- Sticky notes with warnings
- Hierarchical layout

**Generated from:** Prompt #1 (Professor Whiteboard) in [01-pdf-to-visual-learning](../01-pdf-to-visual-learning/prompts.md#1-professor-whiteboard)

### interactive-whiteboard.html
An interactive HTML whiteboard for Google Cloud Services with:
- Clickable sidebar for section navigation
- Whiteboard canvas with service boxes
- Highlight on click with summary panel
- Color-coded categories (Compute, Storage, Networking)

**Generated from:** Dynamic Prompt #1 (Interactive Professor Whiteboard) in [13-dynamic-interactive-prompts](../13-dynamic-interactive-prompts/prompts.md#1-interactive-professor-whiteboard)

## How to View

- **SVG:** Open `notebook-style.svg` in any browser or SVG viewer
- **HTML:** Open `interactive-whiteboard.html` in any browser, click sidebar items to explore

## Color Palette Used

| Color | Hex | Usage |
|-------|-----|-------|
| Navy | #001f3f | Primary text, borders |
| Blue | #0074D9 | Code, highlights, links |
| Green | #2ECC40 | Success, tips, good practices |
| Red | #FF4136 | Warnings, important notes |
