Google Cloud Services: Core Concepts

COMPUTE (Processing & Logic)

GCE (Compute Engine)

IaaS, VMs. Full OS control. Custom apps, legacy migration.

↓

GKE (Kubernetes Engine)

Managed K8s. Container orchestration. Microservices, auto-scaling.

↓

Cloud Run & App Engine

Serverless / PaaS. Abstracted infra. Stateless containers, web apps.

Scale to zero, pay-per-use.

↓

Cloud Functions

Event-driven FaaS. Single-purpose code. Responders, glue code.

STORAGE (Data Persistence)

Cloud Storage (Object)

Global buckets. High durability. Media, archives, backups.

→ Integrates with Cloud CDN
↓

Persistent Disk (Block)

VM-attached drives. High performance. Databases, stateful apps.

↓

Cloud Filestore (File)

Managed NFS. Shared access. CMS, media processing.

↓

Local SSD (Ephemeral)

Attached to host. Extreme performance. Caching, temp data.

Data lost on instance stop.

NETWORKING (Connectivity & Distribution)

Cloud Load Balancing

Global traffic distribution. High availability. HTTP(S), TCP/UDP balancing.

↑

Cloud CDN

Edge caching. Faster delivery. Web content, video streaming.

↑

VPC (Virtual Private Cloud)

Foundational network. Isolation, firewalls. Subnets, routes, security.

Cloud Interconnect

Dedicated link. Low latency. Hybrid workloads.

Cloud VPN

Encrypted tunnel. Secure access. Site-to-site connection.

Hybrid Scenarios
