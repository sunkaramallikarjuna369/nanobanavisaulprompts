# Articles to Social Media Prompts

Transform articles into platform-optimized social media content.

---

## 101. Instagram Carousel

```
Transform this blog post into an Instagram carousel with 10 slides: cover slide with title, key points on subsequent slides, call-to-action at end.
```

**Example:** Input: '10 Python Tips' article → Output: Slide 1: Bold title + author, Slides 2-11: One tip per slide with code, Slide 12: Follow CTA

---

## 102. Twitter Thread

```
Convert this article into a Twitter/X thread format with numbered tweets, each under 280 characters, images for key data points.
```

**Example:** Input: Long-form article → Output: 1/10 thread with hook, subsequent tweets numbered, chart image in tweet 5, conclusion in 10/10

---

## 103. LinkedIn Post

```
Turn this article into a LinkedIn post visual with key takeaway as large text, supporting bullets, and professional imagery.
```

**Example:** Input: Industry analysis article → Output: '3 Key Trends in AI' as header, 3 bullet points, corporate background image

---

## 104. Pinterest Pin

```
Create a Pinterest pin from this how-to article with vertical layout, numbered steps, before/after images, and bold title at top.
```

**Example:** Input: DIY tutorial → Output: Tall vertical graphic with title, Step 1-5 with mini images, 'Save for later' CTA

---

## 105. YouTube Thumbnail

```
Transform this article into a YouTube thumbnail concept with eye-catching text, relevant image, and contrasting colors.
```

**Example:** Input: Tech review article → Output: Split screen: product image left, 'Is it worth it?' text right, bright colors

## 106. TikTok/Reel Script

```
Convert this list article into a TikTok/Reel script visual with on-screen text overlays, transition points, and hook at start.
```

**Example:** Input: '5 Productivity Hacks' → Output: Frame 1: 'You're doing it wrong', Frame 2-6: Each hack with visual example

## 107. Facebook Post

Turn this article into a Facebook/Meta post visual with compelling question as headline, preview of answer, and link prompt.
