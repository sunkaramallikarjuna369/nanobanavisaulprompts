# Text to Diagrams Prompts

Convert text explanations into structured visual diagrams.

---

## 11. Swimlane Flowchart

```
Turn this text explanation into a detailed flowchart with swim lanes for different actors, decision points, and loop-back arrows where needed.
```

**Example:** Input: Order Processing Text → Output: Swimlanes for Customer, System, Warehouse with process boxes in each lane

---

## 12. System Architecture

```
Convert this text into a system architecture diagram with servers, databases, APIs shown as connected boxes with labeled data flows.
```

**Example:** Input: Web App Architecture Text → Output: Frontend box → API Gateway → Backend Services → Database, with HTTP/REST labels

---

## 13. Fishbone Diagram

```
Transform this explanation into a cause-and-effect fishbone diagram with main problem on right, category branches on left.
```

**Example:** Input: Quality Issues Text → Output: Fishbone with 'Defects' on right, branches for Materials, Methods, Machines, People

---

## 14. Quadrant Matrix

```
Create a quadrant matrix from this text with four labeled sections, items plotted based on two axes, and color coding by priority.
```

**Example:** Input: Project Prioritization Text → Output: 2x2 matrix: Urgent/Important axes, tasks plotted as colored dots

---

## 15. BPMN Process

```
Turn this process description into a BPMN-style diagram with start/end events, tasks, gateways, and message flows.
```

**Example:** Input: Approval Process Text → Output: Rounded start → Task boxes → Diamond gateways → Rounded end, with message dotted lines

---

## 16. Layered Architecture

```
Convert this text into a layered architecture diagram showing technology stack from bottom (infrastructure) to top (user interface).
```

**Example:** Input: Software Stack Text → Output: Stacked rectangles: Hardware → OS → Database → Backend → Frontend → UI

---

## 17. Data Flow Diagram

```
Transform this explanation into a data flow diagram with circles for processes, rectangles for entities, arrows for data movement.
```

**Example:** Input: Order System Text → Output: Circles for 'Process Order', 'Update Inventory', rectangles for 'Customer', 'Database'

---

## 18. Network Topology

```
Create a network topology diagram from this text with nodes, routers, connections, and IP ranges labeled.
```

**Example:** Input: Network Setup Text → Output: Cloud shape for internet, router icons, computer nodes, switch icons, labeled subnets

---

## 19. Entity-Relationship

```
Turn this text into an entity-relationship diagram with entities as boxes, relationships as diamonds, cardinality noted.
```

**Example:** Input: Database Schema Text → Output: 'Customer' box → 'Places' diamond → 'Order' box, with 1:N cardinality

---

## 20. Kanban Board

```
Convert this process into a Kanban board visualization with columns for stages and cards for items in each stage.
```

**Example:** Input: Development Process Text → Output: Columns: Backlog, In Progress, Testing, Done with task cards in each
