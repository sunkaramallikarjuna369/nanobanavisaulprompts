# Concepts to Comics & Stories Prompts

Transform abstract concepts into relatable visual narratives.

---

## 41. Comic Strip

```
Turn this complex concept into a 4-panel comic strip with stick figures, speech bubbles, and a simple narrative arc.
```

**Example:** Input: 'How blockchain works' → Output: Panel 1: Person sends money, Panel 2: Network verifies, Panel 3: Block added, Panel 4: Transaction complete

---

## 42. Visual Story

```
Transform this technical process into a visual story with characters representing different components and dialogue explaining their roles.
```

**Example:** Input: HTTP request/response → Output: Client character knocks on Server's door, Server retrieves item, hands it back

---

## 43. Metaphor Illustration

```
Convert this abstract idea into a metaphor-based illustration with real-world objects representing technical concepts.
```

**Example:** Input: API explanation → Output: Restaurant metaphor: Menu = API docs, Waiter = API, Kitchen = Backend

---

## 44. Before/After Comic

```
Create a before/after comparison comic showing problem scenario in first panel, solution in second with visual improvements.
```

**Example:** Input: Load balancing concept → Output: Before: Single server overwhelmed, After: Multiple servers sharing load happily

---

## 45. Roadmap Journey

```
Turn this learning journey into a roadmap illustration with character starting at bottom left, progressing through milestones to goal at top right.
```

**Example:** Input: Career progression → Output: Path from 'Junior Dev' through 'Mid-level', 'Senior', to 'Architect' with skill checkpoints

---

## 46. VS Battle

```
Transform this comparison into a 'vs' battle illustration with two sides showing strengths/weaknesses in visual competition format.
```

**Example:** Input: SQL vs NoSQL → Output: Left side: SQL with relational structure powers, Right: NoSQL with flexibility powers

---

## 47. Domino Effect

```
Convert this cause-effect relationship into a domino-effect illustration showing chain reaction from trigger to outcome.
```

**Example:** Input: Technical debt accumulation → Output: Falling dominoes labeled: 'Skip tests' → 'Bugs' → 'Patches' → 'More bugs'

---

## 48. Maze Puzzle

```
Create a maze/puzzle illustration where solving it represents understanding the concept, with dead-ends showing common mistakes.
```

**Example:** Input: Debugging process → Output: Maze with 'Bug Found' at center, dead ends labeled common wrong assumptions

---

## 49. City Metaphor

```
Turn this technical architecture into a city/building metaphor with structures representing different system components.
```

**Example:** Input: Microservices architecture → Output: City with buildings = services, roads = APIs, utilities = shared services

---

## 50. Recipe Card

```
Transform this process into a recipe card format with ingredients list, step-by-step cooking instructions, and finished dish image.
```

**Example:** Input: Machine learning pipeline → Output: Recipe with 'Ingredients: Raw data, Model', Steps: 'Mix, Train, Bake at 100 epochs'
