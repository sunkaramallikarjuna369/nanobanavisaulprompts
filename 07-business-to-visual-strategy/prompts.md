# Business to Visual Strategy Prompts

Transform business documents into strategic visual frameworks.

---

## 61. Business Model Canvas

```
Transform this business plan into a one-page business model canvas with all 9 building blocks clearly labeled and filled.
```

**Example:** Input: Startup business plan → Output: Canvas with Customer Segments, Value Prop, Channels, Revenue Streams sections filled

---

## 62. SWOT Matrix

```
Convert this strategy document into a SWOT analysis matrix with quadrants for Strengths, Weaknesses, Opportunities, Threats.
```

**Example:** Input: Company analysis → Output: 2x2 grid with bullet points in each quadrant, color-coded internal vs external

---

## 63. Executive Dashboard

```
Turn this quarterly report into an executive dashboard with key metrics as large numbers, trend arrows, and mini charts.
```

**Example:** Input: Financial report → Output: 'Revenue $2.5M' with up arrow, small line chart, '↑15% YoY' indicator

---

## 64. Product Roadmap

```
Create a product roadmap from this plan with timeline, features as cards, and dependency connections between items.
```

**Example:** Input: Product plan → Output: Horizontal timeline Q1-Q4, feature boxes placed above quarters, dotted lines for dependencies

---

## 65. Customer Journey

```
Transform this customer journey into a path with emotional states (happy/sad faces), touchpoints, and pain point markers.
```

**Example:** Input: User experience notes → Output: Curved path with smiley at 'Discovery', sad face at 'Checkout', star at 'Delivery'

---

## 66. Org Chart

```
Convert this org chart into a visual hierarchy with photos (or icons), names, titles, and reporting lines clearly shown.
```

**Example:** Input: Company structure → Output: CEO at top, branching boxes below for VPs, managers, with connecting lines

---

## 67. Marketing Funnel

```
Turn this marketing funnel into a visual pipeline with stages, conversion percentages, and tactics at each level.
```

**Example:** Input: Marketing plan → Output: Inverted triangle: Awareness (Social Ads) → Interest → Decision → Action, % conversions

---

## 68. Competitive Positioning

```
Create a competitive positioning map from this analysis with two axes and competitors plotted as labeled bubbles.
```

**Example:** Input: Market research → Output: Grid: X-axis 'Price', Y-axis 'Quality', competitor circles sized by market share

---

## 69. Value Chain

```
Transform this value chain into a horizontal process flow with primary activities at bottom, support activities at top.
```

**Example:** Input: Operations doc → Output: Arrows showing Inbound → Operations → Outbound → Marketing → Service, support above

---

## 70. Visual Pitch

```
Convert this pitch deck into a single visual pitch with problem, solution, market size, traction, and ask as connected elements.
```

**Example:** Input: 15-slide deck → Output: One page with Problem box → Solution → Market pie chart → Traction graph → Ask $
