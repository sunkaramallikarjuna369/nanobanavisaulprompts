# Data to Visualizations Prompts

Transform datasets into engaging visual representations.

---

## 31. Dashboard Mockup

```
Transform this dataset into an interactive-looking dashboard mockup with charts, KPI cards, filters, and trend indicators.
```

**Example:** Input: Sales CSV data → Output: Dashboard with bar chart for monthly sales, pie chart for categories, KPI cards for totals

---

## 32. Infographic Stats

```
Convert these statistics into an infographic with bold numbers, percentage comparisons, and icon representations.
```

**Example:** Input: Survey results → Output: Giant '87%' with 'agree' caption, comparison bars, stick figure icons for demographics

---

## 33. Line Graph

```
Turn this time-series data into a line graph with multiple colored lines, annotations for significant events, and trend arrows.
```

**Example:** Input: Stock price data → Output: Multi-color line chart with 'Market Crash' annotation, upward trend arrow

---

## 34. Heatmap

```
Create a heatmap from this data with color gradient from cool to warm, axis labels, and value annotations in cells.
```

**Example:** Input: Correlation matrix → Output: Grid with red (high correlation) to blue (low), numbers in each cell

---

## 35. Map Visualization

```
Transform this geographical data into a map visualization with location markers, size indicating magnitude, and color coding by category.
```

**Example:** Input: Store locations CSV → Output: Map with circle markers sized by revenue, colored by region

---

## 36. Treemap

```
Convert this hierarchical data into a treemap with nested rectangles sized by value and colored by category.
```

**Example:** Input: Budget allocation data → Output: Nested rectangles: biggest for largest budget items, color by department

---

## 37. Radar Chart

```
Turn this comparison data into a radar/spider chart with multiple dimensions and overlapping colored shapes.
```

**Example:** Input: Product feature comparison → Output: Pentagon radar chart with 5 features, overlapping shapes for 2 products

---

## 38. Funnel Visualization

```
Create a funnel visualization from this conversion data with labeled stages, drop-off percentages, and narrowing width.
```

**Example:** Input: Sales funnel data → Output: Inverted triangle sections: Visitors → Leads → Trials → Customers, % at each stage

---

## 39. Horizontal Bar Chart

```
Transform this categorical data into a horizontal bar chart with values labeled at end of bars and color gradient.
```

**Example:** Input: Top 10 products → Output: Horizontal bars sorted by revenue, gradient from blue to purple, values at bar ends

---

## 40. Histogram

```
Convert this distribution data into a histogram with bins, frequency counts, and normal curve overlay if applicable.
```

**Example:** Input: Test scores → Output: Bars showing frequency per score range, bell curve overlay, mean/median lines
