# Meetings to Action Items Prompts

Transform meeting notes into visual project management tools.

---

## 111. Action Items Board

```
Transform these meeting notes into a visual action items board with owner avatars, due dates, priority flags, and status indicators.
```

**Example:** Input: Meeting transcript → Output: Kanban board with 'To Do', 'In Progress', 'Done' columns, cards with assignee photos

---

## 112. Decision Log

```
Convert this meeting discussion into a decision log with what was decided, rationale, alternatives considered, and next steps.
```

**Example:** Input: Strategy meeting notes → Output: Table: Decision, Why, Alternatives, Action Items columns filled in

---

## 113. Prioritization Matrix

```
Turn this brainstorm session into a prioritization matrix with ideas plotted by impact vs effort, color-coded by feasibility.
```

**Example:** Input: Innovation meeting notes → Output: 2x2: High Impact/Low Effort (do first) to Low Impact/High Effort (avoid)

---

## 114. Communication Plan

```
Create a stakeholder communication plan from this meeting with audiences, messages, channels, and timing.
```

**Example:** Input: Launch meeting notes → Output: Table with Stakeholder, Key Message, Medium, Date columns for each group

---

## 115. RACI Matrix

```
Transform meeting outcomes into a RACI matrix showing who is Responsible, Accountable, Consulted, Informed for each action.
```

**Example:** Input: Project kickoff notes → Output: Grid with tasks as rows, team members as columns, R/A/C/I in cells

---

## 116. User Story Map

```
Convert this requirements discussion into a user story map with epics across top, user stories below, and priorities indicated.
```

**Example:** Input: Product meeting notes → Output: Swim lanes for epics, story cards below ordered by priority, MVP marked

---

## 117. Retrospective Board

```
Turn this retrospective into a start/stop/continue board with sticky notes grouped by category and vote dots for priorities.
```

**Example:** Input: Retro notes → Output: 3 columns with colored sticky notes, dot voting counts, action items circled

---

## 118. Risk Register

```
Create a risk register from this project meeting with identified risks, probability, impact, mitigation strategies, and owners.
```

**Example:** Input: Risk discussion notes → Output: Table: Risk, Likelihood (H/M/L), Impact (H/M/L), Mitigation, Owner

---

## 119. Gantt Chart

```
Transform this quarterly planning into a Gantt chart view with initiatives as bars, dependencies, and milestones marked.
```

**Example:** Input: Planning meeting notes → Output: Timeline bars for each project, diamonds for milestones, arrows for dependencies

---

## 120. Impact/Influence Grid

```
Convert this stakeholder meeting into an impact/influence grid with stakeholders positioned and engagement strategies noted.
```

**Example:** Input: Stakeholder analysis notes → Output: 2x2 matrix: High/Low Power vs Interest, stakeholders placed, strategy for each quadrant
