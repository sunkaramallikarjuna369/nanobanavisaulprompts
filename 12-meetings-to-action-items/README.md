# Meetings to Action Items

Transform meeting notes into visual action boards and project tools using Gemini.

| # | Prompt Type | Output Style |
|---|------------|-------------|

| 112 | [Decision Log](prompts.md#112-decision-log) | Decision, rationale, alternatives, next steps |

| 114 | [Communication Plan](prompts.md#114-communication-plan) | Audiences, messages, channels, timing |
| 115 | [RACI Matrix](prompts.md#115-raci-matrix) | Tasks vs team members with R/A/C/I |
| 116 | [User Story Map](prompts.md#116-user-story-map) | Epics, stories, priorities, MVP line |
| 117 | [Retrospective Board](prompts.md#117-retrospective-board) | Start/Stop/Continue sticky notes |
| 118 | [Risk Register](prompts.md#118-risk-register) | Risks, likelihood, impact, mitigation |
| 119 | [Gantt Chart](prompts.md#119-gantt-chart) | Timeline bars, milestones, dependencies |
| 120 | [Impact/Influence Grid](prompts.md#120-impactinfluence-grid) | Stakeholders on power vs interest axes |
