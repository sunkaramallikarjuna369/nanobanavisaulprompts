## Prompt 1: Build a Chatbot Project

### Prompt
```
Create a project-based tutorial: "Build an AI Chatbot in Python".
Break it into milestones. For each milestone, provide: objective,
code to write, expected output, and what the student learns.
Milestone 1: Basic echo bot
Milestone 2: Add intent recognition
Milestone 3: Connect to an API for responses
Milestone 4: Add conversation memory
```
