# PDF to Visual Learning Prompts

Transform any PDF into engaging visual learning materials.

---

## 1. Professor Whiteboard

```
Transform this PDF into a professor-style whiteboard image, include diagrams, arrows, boxes, and short captions that explain the core ideas visually. Use color highlights to make concepts easy to follow.
```

**Example:** Input: Machine Learning PDF → Output: Whiteboard with decision tree diagrams, arrows showing data flow, color-coded boxes for supervised vs unsupervised learning

---

## 2. Infographic Summary

```
Convert this PDF into an infographic-style visual summary with icons, flow charts, and key statistics highlighted in vibrant colors. Make it shareable on social media.
```

**Example:** Input: Climate Change Report → Output: Instagram-ready infographic with temperature graphs, emission icons, timeline of events

---

## 3. Mind Map

```
Turn this academic paper PDF into a mind map with central concept in the middle, branches for subtopics, and color-coded connections showing relationships.
```

**Example:** Input: Psychology Research Paper → Output: Mind map with 'Cognitive Bias' at center, branches to 'Confirmation Bias', 'Anchoring', etc.

---

## 4. Step-by-Step Visual Guide

```
Create a step-by-step visual guide from this PDF with numbered circles, directional arrows, and screenshot-style boxes for each major step.
```

**Example:** Input: Software Installation Guide → Output: Numbered workflow with screenshots in boxes, arrows connecting steps

---

## 5. Comparison Table

```
Transform this PDF into a comparison table with side-by-side columns, checkmarks and X marks, and color gradients for better/worse options.
```

**Example:** Input: Product Comparison PDF → Output: Table with Feature A vs Feature B, green checkmarks for pros, red X for cons

---

## 6. Timeline Visualization

```
Convert this document into a timeline visualization with dates on horizontal axis, milestone markers, and callout boxes for key events.
```

**Example:** Input: History PDF → Output: Timeline from 1900-2000 with war markers, invention bubbles, political event annotations

---

## 7. Venn Diagram

```
Turn this PDF into a Venn diagram showing overlapping concepts with labeled circles and color-coded intersection zones.
```

**Example:** Input: Business Strategy PDF → Output: 3-circle Venn showing Marketing, Sales, Customer Success overlap

---

## 8. Flowchart

```
Create a flowchart from this PDF with decision diamonds, process rectangles, and yes/no paths clearly marked with arrows.
```

**Example:** Input: Troubleshooting Guide → Output: Diamond-shaped decisions, rectangular actions, color-coded success/failure paths

---

## 9. Pyramid Hierarchy

```
Transform this PDF into a pyramid/hierarchy diagram with levels labeled and examples at each tier.
```

**Example:** Input: Maslow's Hierarchy PDF → Output: Pyramid with 5 levels, icons at each level, examples in text bubbles

---

## 10. Concept Map

```
Convert this document into a concept map with interconnected nodes, relationship labels on connecting lines, and cluster groupings.
```

**Example:** Input: Ecosystem PDF → Output: Network of connected bubbles for plants, animals, decomposers with arrows labeled 'eats', 'decomposes'
