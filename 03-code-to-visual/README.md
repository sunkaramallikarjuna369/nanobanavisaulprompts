# Code to Visual

Transform code into visual diagrams, execution flows, and architecture views using Gemini.

| # | Prompt Type | Output Style |
|---|------------|-------------|
| 21 | [Execution Flow](prompts.md#21-execution-flow) | Function calls, loops, branches |
| 22 | [Sequence Diagram](prompts.md#22-sequence-diagram) | Lifelines with request/response arrows |
| 23 | [UML Class Diagram](prompts.md#23-uml-class-diagram) | Class boxes with inheritance lines |
| 24 | [State Machine](prompts.md#24-state-machine) | States as circles, transitions as arrows |
| 25 | [Algorithm Walkthrough](prompts.md#25-algorithm-walkthrough) | Step-by-step with intermediate values |
| 26 | [Recursion Tree](prompts.md#26-recursion-tree) | Call stack tree with return values |
| 27 | [Data Structure Visual](prompts.md#27-data-structure-visual) | Nodes, pointers, values |
| 28 | [Component Diagram](prompts.md#28-component-diagram) | UI component hierarchy + data flow |
| 29 | [Query Execution Plan](prompts.md#29-query-execution-plan) | Table scans, joins, filters tree |
| 30 | [Service Mesh](prompts.md#30-service-mesh) | Microservices, load balancers, queues |
