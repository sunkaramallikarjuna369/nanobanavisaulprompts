# Code to Visual Prompts

Transform code into visual representations for understanding and documentation.

---

## 21. Execution Flow

```
Transform this code into a visual execution flow diagram showing function calls, loops, and conditional branches with color-coded blocks.
```

**Example:** Input: Python sorting algorithm → Output: Flowchart with iteration loops in blue, comparisons in yellow, swaps in red

---

## 22. Sequence Diagram

```
Convert this API code into a sequence diagram showing requests, responses, and interactions between components over time.
```

**Example:** Input: REST API calls → Output: Vertical lifelines for Client, API, Database with horizontal arrows for requests/responses

---

## 23. UML Class Diagram

```
Turn this class structure into a UML class diagram with boxes for classes, lines for inheritance, and method/property lists.
```

**Example:** Input: OOP Python code → Output: Class boxes with attributes, methods, inheritance arrows, association lines
