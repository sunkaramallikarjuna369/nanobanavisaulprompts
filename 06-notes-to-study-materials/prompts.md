# Notes to Study Materials Prompts

Transform lecture notes into effective visual study tools.

---

## 51. Flashcard Layout

```
Convert these lecture notes into a flashcard-style layout with question on front (shown as card), answer on back with visual cues.
```

**Example:** Input: Biology notes → Output: Card showing 'What is photosynthesis?' front, flip reveals diagram with sun, leaf, equations

---

## 52. Cornell Notes

```
Transform these notes into a Cornell notes format with cue column, notes column, and summary section with doodles and highlights.
```

**Example:** Input: History notes → Output: Left: Key terms, Middle: Detailed notes with underlines, Bottom: Summary box

---

## 53. Sketchnote

```
Turn these study notes into a sketchnote style with hand-drawn fonts, icons, arrows, speech bubbles, and visual separators.
```

**Example:** Input: Physics concepts → Output: Hand-drawn F=ma with stick figure pushing box, arrows, thought bubbles with examples

---

## 54. Comparison Chart

```
Create a comparison chart from these notes with columns for different theories/approaches and rows for evaluation criteria.
```

**Example:** Input: Psychology theories → Output: Table comparing Freud, Jung, Rogers across 'View of Human Nature', 'Key Concepts'

---

## 55. Visual Syllabus

```
Transform these notes into a visual syllabus with icons for each topic, progress checkboxes, and estimated time bubbles.
```

**Example:** Input: Course notes → Output: Week 1-12 grid with topic icons, empty checkboxes, '2 hrs' time estimates

---

## 56. Concept Relationship Map

```
Convert lecture content into a concept relationship map with key terms in bubbles connected by labeled relationship arrows.
```

**Example:** Input: Economics notes → Output: 'Supply' and 'Demand' bubbles connected by 'determines' arrow to 'Price' bubble

---

## 57. Visual Cheat Sheet

```
Turn these notes into a visual cheat sheet with formulae, examples, common pitfalls, and quick reference tables in organized sections.
```

**Example:** Input: Math formulas → Output: Sections with boxed formulas, solved examples, 'Watch out!' warning boxes

---

## 58. Mnemonics Illustration

```
Create a mnemonics illustration from these notes with memorable images linked to concepts that need memorization.
```

**Example:** Input: Periodic table elements → Output: Visual story connecting images: 'Harry' (Hydrogen) 'Helps' (Helium)...

---

## 59. Exam Prep Grid

```
Transform these notes into an exam preparation grid with topics, difficulty level, importance ranking, and status indicators.
```

**Example:** Input: Study topics → Output: Grid with Topic, Stars for difficulty, Red/Yellow/Green for mastery, Checkbox for reviewed

---

## 60. Visual Glossary

```
Convert these notes into a visual glossary with terms in bold, definitions in simple language, and illustrative diagrams.
```

**Example:** Input: Technical jargon → Output: 'API' in big letters, simple definition, diagram showing request/response arrows
